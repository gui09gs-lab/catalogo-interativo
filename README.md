# Catálogo Interativo Kilews

App (PWA) do catálogo interativo Kilews para a equipe Feromax. Instala na tela inicial do celular e funciona sem internet.

O conteúdo do catálogo vai criptografado em `catalogo.enc` e só abre com a senha da equipe. Os arquivos-fonte não ficam neste repositório; eles ficam na pasta `app-pwa/fonte/` do projeto, onde `build.py` gera estes arquivos.
